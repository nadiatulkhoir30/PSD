4. Identifikasi Outlier#

Outlier pada dataset ini diidentifikasi menggunakan dua metode statistik:

Z-Score – mengukur seberapa jauh nilai tiap data dari rata-rata dalam satuan standar deviasi. Data dengan |Z| > 3 dianggap outlier. Hasilnya ditemukan 1 sampel outlier.

IQR (Interquartile Range) – mendeteksi data yang berada di luar 1,5×IQR dari kuartil bawah (Q1) atau atas (Q3). Hasilnya ditemukan 4 sampel outlier.

# Identifikasi Outlier (Z-Score & IQR)
from scipy import stats

print("\n--- Identifikasi Outlier ---")
print("="*45)

# Z-Score
z_scores = np.abs(stats.zscore(df.select_dtypes("number")))
outliers_z = (z_scores > 3).any(axis=1)
print(f"Jumlah outlier (Z-Score): {outliers_z.sum()} sampel")

# IQR
Q1 = df.select_dtypes("number").quantile(0.25)
Q3 = df.select_dtypes("number").quantile(0.75)
IQR = Q3 - Q1
outliers_iqr = ((df.select_dtypes("number") < (Q1 - 1.5 * IQR)) |
                (df.select_dtypes("number") > (Q3 + 1.5 * IQR))).any(axis=1)
print(f"Jumlah outlier (IQR): {outliers_iqr.sum()} sampel")

# Menampilkan baris outlier (jika ada)
df_outliers = df[outliers_z | outliers_iqr]
print("\nData outlier:")
display(df_outliers.head())
